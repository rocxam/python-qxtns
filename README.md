# Python Questions: OOP and Data Processing

This repository contains the solutions for Questions 1 through 6. Each question remains in its own file so that the datasets, processing logic, and report output can be reviewed independently.

## Contents

| Question | File | Description |
| --- | --- | --- |
| 1 | `qstn1.py` | School cafeteria meal planning and weekly spending report |
| 2 | `qstn2.py` | Community library book donation manager |
| 3 | `qstn3` | Small business sales performance monitor |
| 4 | `qstn4.py` | Clinic patient status classification system |
| 5 | `qstn5.py` | University course enrollment and grade tracking system |
| 6 | `qstn6` | Design reflection: reorganizing student data with classes |

Questions 1 to 5 are executable Python scripts. Question 6 is a written reflection about how the Question 5 solution could be redesigned using object-oriented programming.

## Requirements

- Python 3.8 or newer
- No external packages are required

## Running the programs

From the repository folder, run any executable question with:

```powershell
python qstn1.py
python qstn2.py
python qstn3
python qstn4.py
python qstn5.py
```

Questions 1 to 5 print reports for their supplied datasets. Most also include an additional test dataset containing extra records and edge cases.

## Learning focus

The solutions demonstrate:

- Lists, tuples, and nested dictionaries
- Loops and conditional logic
- Aggregation and grouping of records
- Functions and reusable report generation
- Sorting and selecting summary results with `sorted()` and `max()`
- Classification, averages, thresholds, and basic validation scenarios
- The transition from procedural data handling toward classes and encapsulation
